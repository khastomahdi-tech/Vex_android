# VEX CLIENT (Android)

کلاینت VPN اندرویدی با هسته‌ی واقعی sing-box (libbox v1.11.15) و **رابط کاربری کاملاً نیتیو Kotlin** (بدون WebView / HTML).

## پروتکل‌های پشتیبانی‌شده
- **VLESS** (TLS / Reality / Vision / WS / gRPC / HTTPUpgrade / QUIC / TCP-HTTP)
- **VMess** (TLS / WS / gRPC / HTTP)
- **Trojan**
- **Shadowsocks** (SIP002 + پلاگین obfs/v2ray-plugin)
- **Hysteria2** (hy2)
- **TUIC**
- **WireGuard** (بخش جدا: فایل conf / پیست / تنظیم دستی)

> محدودیت: ترنسپورت **XHTTP (splitHTTP)** و **mKCP** در هسته پشتیبانی نمی‌شود.

## امکانات
- رابط کاربری ۱۰۰٪ نیتیو Kotlin با پشتیبانی کامل RTL فارسی
- اتصال یک‌ضربه‌ای مانند v2rayNG + تست واقعی اینترنت از مسیر سرور (بدون قطع خودکار)
- ذخیره‌ی دائمی سرورها و تنظیمات (بعد از بستن برنامه می‌مانند)
- پینگ واقعی TCP هنگام افزودن سرور و دکمه‌ی «پینگ همه»
- پیست کانفیگ از کلیپ‌بورد، وارد کردن فایل، اسکن QR (دوربین + گالری)
- افزودن دستی با فرم کامل (شبکه، امنیت، Reality، uTLS fingerprint و...)
- دریافت لینک اشتراک (subscription) به‌صورت نیتیو (پشتیبانی از http/https و بدنه‌ی base64)
- آمار ترافیک لحظه‌ای و تجمعی از شمارنده‌ی واقعی تونل
- تم شیر و خورشید (با خورشید متحرک)، تیره، روشن و هماهنگ با سیستم
- اتصال خودکار هنگام باز شدن برنامه + سوییچ خودکار بین سرورها هنگام اتصال
- لاگ کامل هسته برای اشکال‌زدایی + جزئیات خطا

## دانلود APK
از بخش **[Releases](https://github.com/khastomahdi-tech/Vex_android/releases)** آخرین نسخه را دانلود و نصب کن (اجازه‌ی نصب از منابع ناشناس لازم است).

فایل `app-debug.apk` روی همه‌ی اندرویدهای ۷.۰ به بالا (arm64 / arm / x86_64) اجرا می‌شود.

## ساخت APK
### روش ۱: خودکار با GitHub Actions
1. تب **Actions** → **Build APK** (روی push به main هم خودکار اجرا می‌شود).
2. بعد از اتمام، APK به‌صورت خودکار در **Releases** منتشر می‌شود (و در Artifacts هم هست).
3. هسته‌ی sing-box با gomobile ساخته و کش می‌شود (نیازی به فایل AAR نیست).

### روش ۲: محلی
```bash
# ابتدا libbox.aar را بساز یا از release دانلود کن و در app/libs/ بگذار
./gradlew :app:assembleDebug
```

## معماری
- `MainActivity` + `HomeUi` / `ServersUi` / `SettingsUi` / `DialogsHelper` — UI نیتیو (بدون HTML)
- `PowerButtonView` — دکمه‌ی پاور سفارشی با انیمیشن
- `VexVpnService` — سرویس VPN + پیاده‌سازی PlatformInterface هسته
- `CoreEngine` — پل به libbox (BoxService)
- `ConfigBuilder` — ساخت کانفیگ کامل sing-box از لینک/JSON/وایرگارد
- `LinkParser` — تحلیل لینک‌ها، فایل conf وایرگارد و بدنه‌ی اشتراک
- `ServersStore` — ذخیره‌سازی دائمی سرورها و تنظیمات
- `NetUtil` — پینگ TCP واقعی + دریافت اشتراک

## نسخه‌ی فعلی: v3.0.0 (versionCode 8)
- v3.0.0: ریشه‌یابی و رفع نهایی «سرور وصل می‌شود ولی داده رد و بدل نمی‌شود» —
  **trojan بدون TLS** (خیلی از لینک‌های trojan پارامتر security را نمی‌آورند و برنامه کانفیگ را بدون TLS می‌ساخت)،
  fallback خودکار SNI از پارامتر host برای سرورهای IP-محور (سناریوی Cloudflare/CDN)،
  پشتیبانی از skip_cert_insecure، نمایش دلیل واقعی خطا از لاگ هسته در پیام تست اینترنت؛
  **UI سلطنتی جدید کاملاً مطابق طرح مرجع** — هدر تاج و VEX CLIENT با نشان V و دکمه‌ی تلگرام،
  کارت وضعیت با نقش شیر و خورشید، دکمه‌ی پاور تاج‌دار با حلقه‌ی گرادیانی طلایی و دو شیر بالدار،
  کارت‌های آمار با قاب دوبل طلایی، کارت سرور با نشان قرمز پروتکل + تاج و پینگ آنتنی،
  دکمه‌ی شناور «+»، نوار پایین چهارتیکه (خانه / کانفیگها / آمار / تنظیمات) با آیکون‌های وکتوری،
  و صفحه‌ی جدید «آمار» (سرعت لحظه‌ای، مجموع جلسه، مدت اتصال، تست اینترنت و جزئیات خطا)
- v2.0.0: بازنویسی کامل UI از WebView/HTML به **Kotlin نیتیو** (حذف ۱۵۸۳ خط HTML)،
  رفع بلاک‌شدن اشتراک‌های http (usesCleartextTraffic)، رفع کرش نوتیفیکیشن روی اندروید ۷،
  افزودن فرم دستی کامل (Reality/fingerprint/alpn)، وایرگارد از فایل conf،
  تغییر نام سرور، سوییچ خودکار سرور هنگام اتصال، اتصال خودکار، بازگردانی وضعیت پس از بستن برنامه،
  پینگ خودکار پس از افزودن، تم شیر و خورشید با خورشید متحرک
- v1.3.0: اتصال v2rayNG-سازگار (تست اینترنت پس‌زمینه، بدون قطع خودکار)، پشتیبانی Hysteria2/TUIC/WireGuard،
  رفع پیست کلیپ‌بورد، ذخیره‌ی دائمی تنظیمات، پینگ خودکار هنگام افزودن، دریافت اشتراک، Mux
