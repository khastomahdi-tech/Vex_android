# VEX CLIENT (Android)

## ساخت APK روی GitHub
1. این پوشه را در یک ریپوی جدید گیت‌هاب آپلود کن (شاخه‌ی main).
2. تب **Actions** → **Build APK** → **Run workflow**.
3. بعد از اتمام، در صفحه‌ی همان اجرا بخش **Artifacts** را باز کن و `vex-client-apk` را دانلود کن.
4. فایل `app-debug.apk` را روی گوشی نصب کن (اجازه‌ی نصب از منابع ناشناس لازم است).

## وضعیت فعلی
- رابط کاربری (HTML) داخل `app/src/main/assets/index.html` است و از طریق `window.VexNative` به اندروید وصل است.
- درخواست اجازه‌ی VPN، ساخت تونل (TUN) و نوتیفیکیشن فورگراند پیاده شده است.
- تبدیل لینک‌های vless / trojan / ss / vmess به کانفیگ sing-box در `ConfigBuilder.kt` است.
- **هسته‌ی پروکسی (sing-box / libbox) هنوز وصل نشده است.** تا وصل شدن هسته، دکمه‌ی پاور خطا می‌دهد
  (عمداً، تا اینترنت گوشی قطع نشود). ترافیک و سرعت واقعی بعد از اتصال هسته نمایش داده می‌شود.
